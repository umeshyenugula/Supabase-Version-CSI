How the site works

CSI GRIET is a single-page site — only index.html ever loads. Everything else is fetched and swapped in as you click around.

1

One shell, many pages

The navigation bar, footer, and cookie banner load once. When you click a link like "Events" or "Team", the site fetches just that page's content and slots it in — no full reload, no flash.

2

Live data from our database

Events, team members, alumni stories, and certificate records are stored in a database and pulled in fresh. The Home page always re-checks for the latest events and announcements every time you land on it.

3

Smart caching, not stale data

Pages like Team and Alumni cache their data for a short while so navigating back feels instant. Refresh the page anytime to force a clean reload.

4

Clean URLs

Every page has its own shareable link — /events, /team, /certificates — so you can bookmark or send a direct link to any section.

Troubleshooting guidelines

Most issues clear up with a refresh. Here are the common ones:

The Home page looks empty or outdated on first load

This can happen right after the site updates in the background. Navigate to any other page and back to Home, or simply refresh the page once — it always pulls the latest data on load.

My certificate PDF won't download

The certificate tool needs a couple of small helper libraries to load from the network. On a slow or restricted connection (or with certain ad-blockers / browser extensions enabled) these can be delayed. Wait a few seconds and try the download button again — it will automatically retry once the tools are ready. If it still fails, try disabling browser extensions for this site or use a different network.

I can't find my name in the certificate search

Make sure you've selected the correct academic year and event first — name suggestions are scoped to that event. Names are matched against the official participant list for that event, so check for typos or try a partial name. If your name is genuinely missing, reach out using the contact details below.

Images or photos aren't loading

Photos are loaded from external image hosting and load lazily as you scroll. If a particular image consistently fails, it's usually a temporary hosting hiccup — refreshing the page resolves most cases.

A page shows "Page failed to load"

This means the page content couldn't be fetched — usually a momentary network blip. Refresh the page; if the issue persists, please report it using the feedback links in the footer.

The site looks broken on my browser

The site is built and tested for the latest versions of Chrome, Safari, Firefox, and Edge. If something looks off, try updating your browser or switching to one of these.

Still stuck?

Reach out and we'll sort it out — or use the feedback links in the footer to report a bug.
