# Images Required

Place the following files in this directory (`assets/images/`):

| Filename | Used in | Notes |
|---|---|---|
| `csi-logo.png` | Navbar, Footer badge, Mobile menu, Page loader spinner | Transparent background recommended, square |
| `griet-logo.png` | Navbar (second logo) | Transparent background recommended, square |

Both logos are used with `object-fit: contain` inside square containers.
Fallback text (CSI / GRI) is shown automatically if images are missing.
